# 源码包内容清单

`TianqueArena-Source-v1.0.zip` 包含：

- 可直接由 Godot 4.7.2 打开的完整游戏项目。
- 全部运行时角色资产；庭院由代码生成，不再包含远景大雁塔。
- 五个角色的可编辑 Blender 工程。
- 重建五个角色所需的 Quaternius CC0 原始 FBX、贴图和许可。
- 稳定的角色构建、GLB 检查、macOS 打包脚本。
- 当前版本实机参考截图和中文开发指南。

有意排除：

- `.godot/` 导入缓存。
- `dist/` 中的已发布应用与 DMG。
- `.blend1`、`.DS_Store`、`__pycache__` 等本机生成文件。
- 废弃的 MakeHuman/MPFB 试验、旧程序化主角和只依赖作者临时目录的一次性诊断脚本。

源码包根目录名固定为 `TianqueArena-Source-v1.0/`。
