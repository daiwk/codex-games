# 2026-10-27 · 两版代码同步、马战方向与跳跃

本次同时交付《问锋》与《长坂行》的当前源码、运行资产、授权说明和完整静态构建。此前 GitHub main 停在 ad9858b；后续表现、响应、六将阵列与骑战改动只保存在工作目录及 Sites 源仓库。本次同步包含这些累计成果。

## 行为

- 单挑马战的 A/D、左右方向键与触屏方向在玩家输入边界转换为正确旋转符号；AI继续使用原世界角度。Z/C左右出招和HUD同样按骑手真正的左右显示。
- V 或屏幕跳跃按钮：步战人物跳跃、马战人与马一同跳跃；不占用攻击/技能状态。Space、F既有功能保留。
- 真正的重力、地面/低顶碰撞、单次起跳、暂停与复位；空中仍可出招。长蓄力招式允许按原时长落地完成，不强制所有技能在空中结束。
- 跳跃下身与马腿使用现有免费 KayKit/Horse 动作旋转，不替换原始用户GLB。新来源哈希与生成器随源码保留。
- 空中换马先停用旧碰撞体，再生成落地的新坐骑，防止延迟释放时互相顶起。存档格式不变。
