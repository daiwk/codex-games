# Wizard single-sword source candidate

Original **Wizard by AnthonyMyers**, [OpenGameArt](https://opengameart.org/content/wizard-4), [CC BY3.0](https://creativecommons.org/licenses/by/3.0/). This original Blender file is unchanged; no target character or weapon replacement is proposed. Source/ZIP SHA and author attribution are in SOURCE.json. The larger original ZIP and source inspection renders are retained in ignored local QA.

One moving action, original frames1–30 at25fps (endpoint span1.16s); right-hand sword and left-hand staff. It contains a complete visible lift/cut/follow-through into a different upright guard, not a ready-to-ready loop. No separate Idle/Block or combo clips are present; robes hide the feet. Other single-frame actions are static object transforms.

**Source candidate only; not retargeted, installed, built, deployed or accepted as an improvement.** A legal downloadable source does not establish adequate weight, footwork, character fit or continuous combat. Inspection used Blender5.2.1 with --disable-autoexec; no embedded script was executed.

Full-source review rejects this as a useful Xu heavy-cut replacement: light arm-led cut, limited visible body commitment, staff-dependent left arm and unmatched start/end. It is retained for source traceability, not another adaptation to implement.
