# Original Lugaru staff source candidates

Original Wolfire Games assets from the [official OSS Lugaru repository](https://github.com/osslugaru/lugaru), [CC BY-SA3.0](https://creativecommons.org/licenses/by-sa/3.0/). See the unchanged CONTENT-LICENSE.txt and per-file URLs/SHA in SOURCE.json. These asset files are distinct from the upstream GPL source code; no upstream C++ implementation is included here. Original binaries are unchanged. Attribution and ShareAlike apply to derived assets.

StaffHit/SpinWhack and their paired Catch/Caught roles are original10-key/20-joint binary animations, not GLB/BVH. BasicFigure supplies labels and muscle endpoints. Key speeds govern time; there is no invented fixed source FPS. Weapon targets are direction markers, not complete staff meshes, roll or full prop extents. Left-hand grip is not maintained throughout.

**Not runtime assets and not accepted replacement motions.** StaffHitCaught is the losing participant in a paired reversal, inherits attack frame indices, and exits toward a backhandspring; it is not a generic ordinary parry-to-Ready reaction. The original game's ordinary staff/weapon parry uses SwordSlashParried. Do not rename that paired defeat into Zhao GuardBreak or treat legal acquisition as quality acceptance.

Original-loader evidence, complete parsed arrays and a literal source-clock skeleton preview are retained in ignored local QA/combat-quality-2026-10-30/new-acquired-source. No Zhao retarget, generated GLB, IK or controller is included here.
