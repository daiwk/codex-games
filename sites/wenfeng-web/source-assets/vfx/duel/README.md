# 六将兵器阵列与素材来源

本目录记录2026-10-26《问锋》1v1当前的六种U阵列和Q/E兼容机制。没有新增购买素材，未提取参考商业游戏的模型、动作、纹理、音频或影片作为运行素材。角色动作沿用已归档的免费 KayKit / Quaternius UAL1、UAL2，重编动作阶段和节拍，再配合程序阵列、骑姿与转向；不是新增动作捕捉片段。

| 武将U | 当前装备几何与实际路径 | 满额名义伤害 |
|---|---|---|
| 赵云 · 七曜龙矛 | 7支3.5米丈八蛇矛，3/2/2三轮直线齐射，目标释放时固定 | 7×10=70 |
| 马超 · 西凉铁骑 | 6骑、三路两排，附程序小旗与合批蹄尘，实际冲锋经过才接触 | 6×12=72 |
| 关羽 · 青龙刀阵 | 3把3.3米青龙刀斜列，错峰斩进 | 3×24=72 |
| 张飞 · 蛇矛破军 | 5支3.5米蛇矛，低位分道、两翼收束；骑战提高至实际骑手高度 | 5×14=70 |
| 吕布 · 无双方天阵 | 6把3.5米方天戟围住固定阵心，0.55秒可见预示后从多向包夹；足骑均地面施展 | 6×12=72 |
| 许褚 · 虎啸回刃 | 3把当前专用大刀/单手刀/剑，错峰扇形抛回；前两刃轻推，最后一刃实际接触才重推 | 3×22=66 |

所有U需要100战意，资源与冷却在施展时扣一次，多个投射物不重复收费。满额不代表实战保证伤害：每实体必须实际接触，格挡、墙体、提前闪离或策马冲出路径均可使部分/全部落空；每实体对同一对手最多一次。阵列在释放时固定目标与路线，不追加瞬移追踪。吕布的生成点与路径也受墙体遮挡，不能隔墙包夹。

Q/E仍保留原武将技能，包括关羽Q推进刀气、张飞E扩散战吼、许褚Q单抛当前兵器。许褚Q与三刃U共同记录尚未回手的兵器，仍有一刃在外时不会提前显示手持武器或恢复普通轻重击；取消、死亡和重置统一回收。

兵器阵列按 `Roster.WEAPONS` 当前装备路径读取原有几何，场景启动时预暖所有六将可选装备的单元网格，再按合理长兵器尺寸设置实例。模型路径、输入SHA256、队形和许可边界见 [ARMY_SOURCE.json](ARMY_SOURCE.json)。用户提供的角色、马匹和兵器不声明为CC0，本轮不改写原始GLB。

六骑轮廓来自 `godot/assets/mounts/horse_white.glb`、`godot/assets/characters/machao.glb`、`godot/assets/weapons/serpent_spear.glb`；四相位奔跑来自已有 Quaternius Farm Animal Pack 的 CC0 Gallop，许可见 `godot/assets/licenses/Horse-CC0.txt`，原件来源在 `source-assets/animations/horse/`。`godot/tools/prepare_duel_cavalry.gd` 离线生成每骑4,894三角形的低精度阵列；最多六骑，共享一个MultiMesh与四姿态纹理，不新增六套骨架。两个派生资源共396,599字节，哈希见 `godot/assets/vfx/duel/SOURCE.json`。

旗帜、飞行轨迹、低位压力、短切痕、聚能和金属碎屑为程序网格/shader。蹄尘、地波软尘簇和局部火花沿用已有 Kenney Particle Pack 1.1 CC0 纹理；原图、许可与哈希见 `source-assets/vfx/kenney/`。声音仍为程序合成。短时表现最多24层，特殊技最多18实体/6组，支持暂停及完整回收。

`godot/tools/duel_army_test.gd` 是当前六将足骑的独立物理/几何专项；完整Main的输入、资源、实际击退与镜头由场景和浏览器套件独立验收。旧版报告按原快照保留，不覆盖阴性记录或伪装成当前版本结果。
