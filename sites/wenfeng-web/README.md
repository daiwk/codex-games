# 问锋 · Web 开发说明

这是可独立重建的 Godot 4.7.2 网页版源码。六位角色赵云、马超、关羽、张飞、吕布、许褚，两把枪、三把长兵器及许褚可选的三种刀剑、三档 AI、自由选对手、三局两胜和角色专属技能都包含在 `godot/`。人物运行贴图最高 1024px，坐骑与马鞍按各自准备配置保留细节；人物几何、骨骼与烘焙动画仍保留。3D 使用完整渲染分辨率与 2× MSAA，画布最高 2× 屏幕像素密度、3840×2400 像素，UI 使用 1280×800 逻辑坐标。

## 直接游玩

在仓库根目录运行 `python3 play.py`，或双击 `play.command`（macOS）/ `play.bat`（Windows）。只需要 Python 3.9+ 和支持 WebGL 2 / DecompressionStream 的浏览器。`dist/` 已包含游戏、字体、图像和许可，完整下载后无需联网。

## 修改和重建

只有修改游戏源码或重新导出才需要安装 **Godot 4.7.2**。构建脚本使用 Python 标准库；首次下载导出模板时需要 `curl`，只下载官方模板中的单线程 Web release 模板，并校验固定 SHA256。字体子集和优化后的模型已随源码提供，无需 Pillow、fontTools 或旧桌面工程。

在本目录运行：

```sh
python3 tools/build_web.py --godot /absolute/path/to/Godot
```

也可以把 `godot` / `godot4` 加入 PATH，或设置 `WENFENG_GODOT`。macOS 上会自动检查 `/Applications/Godot.app/Contents/MacOS/Godot`。脚本首次缺少模板时会自动下载到忽略的 `.cache/`；需要代理时设置 `HTTPS_PROXY`。也可提前单独下载：

```sh
python3 tools/fetch_web_resources.py
```

游戏逻辑在 `godot/scripts/`；场景在 `godot/main.tscn`；运行资源在 `godot/assets/` 和两把兵刃 GLB。网页外壳在 `web/shell.html`，加载器和样式在 `web/web-app.js`、`web/web.css`，浏览器交互桥接在 `web/web_bridge.gd`（修改后同步到 `godot/scripts/web_bridge.gd`）。重建会更新 `dist/`，随后运行根目录的启动脚本查看效果。

当前六将技能使用 `godot/tools/role_identity_test.gd` 检查实际出招、逐击伤害、资源门槛及骨骼轨迹差异；`wrist_pose_test.gd` 检查最终持握与蒙皮，同时保留保守的转速诊断，`duel_lock_test.gd` 检查锁定输入与镜头。运行方式为 `Godot --headless --path godot --script res://tools/role_identity_test.gd -- --rpg-test`，替换脚本名即可运行其余检查。早期 `polearm_test.gd` 与内置 `--skills-test` 保留旧版技能断言，不能作为当前六将技能的验收结果。

`godot/tools/` 保留游戏源码使用的回归和场景检查工具。生成的导入缓存与 `qa/` 输出均忽略，不进入仓库。

## 部署文件

`dist/` 是完整静态站点，使用单线程 WebGL 2，不要求 SharedArrayBuffer 或跨域隔离。WASM 与 PCK 以 gzip 提供，超过上限的压缩包拆为 16 MiB 分片，由加载器按顺序流式拼接、解压，不设置 `Content-Encoding: gzip`；每个文件小于 25 MiB。`assets-manifest.json` 记录下载大小、解压大小和 SHA256。重建后可在仓库根目录运行 `python3 play.py --check` 验证。

现有 Sites 身份记录在 `.openai/hosting.json`。仓库根 Git 统一用于 GitHub，不再包含嵌套 Git 仓库。更新 Sites 时保留该项目 ID，并使用 Sites 的源码同步与部署流程。

## 马战

选将菜单可切换步战/马战（B）；默认步战。马战复用六将，使用约56米宽的专用马场。**W** 加速、**S** 减速至倒退，松键保持巡航，**A/D** 转马，**X** 急刹、**Space** 催马。**Z/C** 指定左/右侧直击，**J/K** 自动选择近侧；Q/E保留各将技能，U为下文的六种阵列。锁定只控制标记与镜头，马身保持实际朝向，不自动横移绕敌。速度、转弯半径与出手侧决定接战路线；双方均骑乘，以武将生命判胜，当前无上下马/落马系统。

`horse_visual.gd` 使用 `assets/mounts/horse_brown.glb`、`horse_white.glb`，保留用户提供的真实毛色和贴图，双方坐骑可分别选色。鞍座与鞍垫使用用户提供的马鞍，侧垫分别适配两匹马，马镫跟随骑手靴子；`rider_pose.gd` 在动画后通过SkeletonModifier3D固定髋部和跨马双腿，保留上身攻防，不修改原始人物GLB；`mounted_combat.gd`定义枪刺、刀戟挥斩和骑乘技能。站立马匹的身体碰撞与骑乘者合并为同一角色碰撞体，当前不支持独立击杀马匹。用户马匹原件在 `source-assets/mounts/`，参考骨架、动作和许可在 `source-assets/animations/horse/`。

用户提供的 `马_棕色.glb` / `马_白色.glb` 原件仅用于归档：原导出无动画，骨骼静止变换与逆绑定矩阵异常且几乎所有权重集中于Root，不能直接用于跑步。网页副本保留外观、UV和贴图，按已验证的四足参考骨架重新绑定并接入CC0站立/行走/奔跑动作；转换方式与数据详见 `tools/prepare_mounts.py` 及 `assets/mounts/` 内记录。

`马鞍.glb` 原件也完整保留。运行 `python3 tools/prepare_saddle.py` 生成 `assets/mounts/saddle.glb` 与 `saddle_manifest.json`：保留原三角形、UV、鞍桥和厚度，将贴图缩为2048px。运行副本纵长约68cm（原约90cm），两端平滑缩短而保留中央座区，鞍与骑手前移7.5cm，侧垫分别贴合两匹马。白马适配使用同一模型的形态键，不复制整套纹理。位置参考 [BHS骑具检查](https://www.bhs.org.uk/media/uddbc0np/connemara-champs-activity-plans.pdf) 与 [World Horse Welfare / Animal Health Trust](https://storage.googleapis.com/worldhorsewelfare-cloud/2021/11/9c136a57-saddlery-leaflet-2021.pdf) 的肩胛避让、承重区域与骑手居中原则；尺寸按游戏网格标定。此可选素材准备步骤需要NumPy、SciPy和Pillow，直接运行已打包的游戏无需安装这些库。

马匹使用独立的站立、行走和奔跑片段，奔跑保留原动作的收腿、伸展与腾空。低速至1.8m/s使用完整Walk，1.8–3.6m/s平滑过渡到完整Gallop，达到奔跑速度时使用完整Gallop，不再掺入Walk；Space冲刺提高完整奔跑片段的节奏。切换与节奏连续，骨长和马GLB保持不变。`godot --headless --path godot --script res://tools/horse_gait_test.gd` 验证实际腿部摆幅、骨长、速度切换及停止/重置。

## 突刺接触

直刺的射程与前方窄线仅做初筛，实际伤害还须兵刃或上一帧刀尖轨迹接触躯干。`thrust_contact.gd` 在动画与骑姿之后限制过深的伸枪，近身时向准备姿态缩短刺幅，并用双臂IK保持握杆、骨长和武器长度。命中或格挡后收枪并停止本段前冲，连刺每段重新允许出招；闪避、招架、挥砍和震喝保留各自规则。运行 `godot --headless --path godot --script res://tools/thrust_contact_test.gd` 可验证接触、近身、连刺和防守回归。

### 赵云真人移动动作（2026-10-29）

赵云步战单挑的前跑与后退改用 CMU 真人录制动作09_01、136_25（Normal Walk Backwards）。按来源完整周期匹配实际位移：前进仍为2.85m/s，后退为1.05m/s；后退沿用正常倒走动作并统一加快节奏，快速脱离继续使用闪避。原46段动画保留，其他角色、马战和RPG继续使用原片段。

离线仅做骨架参考姿态适配、恒定高度摆放、朝向/根位移处理和统一时间缩放。脚掌参考依据实际鞋底，保留真人原有抬脚与脚掌转动；上肢沿用持枪姿态并跟随真人躯干。未使用此前被否决的程序脚步轨迹。来源、原始ASF/AMC和使用条款在 `source-assets/animations/cmu-locomotion/`；`tools/prepare_recorded_locomotion.py` 从精确归档的旧运行基线追加两个新片段，可独立重建。若重新准备整个角色库，最后运行这一步，再导出Web。

步战切换前进、侧步、后退时保留归一化步态相位，方向选择增加迟滞，播放速率平滑变化。六位武将重新烘焙后的七种移动片段保留16%的作者原始上身摆动，再以同一武器轴求解双臂握持，避免腰以上完全冻结。仍使用已归档的 KayKit CC0 动作；本轮未替换用户人物原件，枪矛的进攻仍为双手直刺。

`combat_motion.gd` 在原动作之后加入小幅腰胸惯性、呼吸和视线稳定；攻击有效窗口及大招期间不叠加姿态偏移。`rider_pose.gd` 通过阻尼弹簧吸收实际马鞍倾斜、转弯与加减速，髋部与跨马双腿继续保持原来的座点和净空约束。骑手及马匹每次骨骼更新后都会重新对齐座点，并刷新双手兵器附着，避免低帧率下多个物理帧共用旧马鞍高度。

技能特效共用 `textured_skill_fx.gd` 的纹理合批层：柔化烟尘与火星轮廓，加入柔光聚能和分层刀枪光痕，收窄粗硬冲击圈。枪刺与挥砍保留各自的方向，径向震喝才使用周身效果；大招光痕等待实际 strike/finish 事件，视觉不扩大伤害范围。新素材来自 [Kenney Particle Pack 1.1](https://kenney.nl/assets/particle-pack) 的五张 CC0 PNG；运行副本均为256×256，合计113,569字节。原图、许可、来源及SHA256保存在 `source-assets/vfx/kenney/`。每层使用合批网格，统一最多24层短时效果，支持暂停、取消及完整回收，无需依赖HDR或bloom。

《问锋》与《长坂行》共用本目录的 Godot 角色、动作和特效模块；RPG保留专属表现入口 `rpg_skill_fx.gd`。两款网站仍分别构建、分别发布，各自保留Site身份、入口和浏览器存档。当前开发与核查记录见 `qa/progress.md`；本轮最终原生/浏览器复测、Web导出及两个Sites部署结果由发布流程补记。


## 动作节拍与冲击层次（2026-10-24）

本轮对照《黑神话：悟空》《艾尔登法环》《光与影：33号远征队》的官方资料与可读取画面，强化起手、出手、收势以及动作/镜头/特效的协同；来源与实际查看范围见 [参考记录](source-assets/vfx/kenney/PRESENTATION_REFERENCES.md)。参考作品仅用于表现研究，新增运行素材使用免费 Kenney CC0 纹理、KayKit / UAL2 CC0 动画及程序网格。

`attack_tempo.gd` 只重定时 Spine 以上的普通轻重击：起手逐步蓄势、临触前加速、收招短停后回稳。髋部、双腿和脚趾始终保持原 key，避免延迟原脚步而产生滑步。命中有效区间及前后各50ms保持全部原骨骼姿态，普通轻重击的总时长保留；Q/E/U使用下文的武将独立阶段与动作。破风声在有效段前55ms附近随实际出手触发，打断不会补响。

刀气采用扫描、蚀散的曲面带，枪刺使用窄锥面及前向压力雾，保留暗肩、角色色与短亮芯。真实接触才产生局部切痕、热核、火花及重击碎屑，避免释放光痕假冒命中。`impact_feedback.gd` 合并同一短时段的冲击，单次停顿最多90ms、重启间隔160ms；`combat_camera.gd` 以实际起手时间聚焦，在独立镜头基准上叠加不超过10cm的弹簧回弹。贴身换位时镜头方向限速，RPG最后一层遮挡检测仍覆盖震动与回弹。

检查结果写入忽略的 `godot/qa/`。RPG相关套件要求 `--rpg-test`，避免读取或写入真实存档。

## 锁定视角

每场新对决默认锁定对手。按 **Tab**、点击**鼠标中键**或网页顶部的**锁定视角**按钮切换。步战锁定时镜头从己方身后跟随对手，敌人身上显示标记；**W/S** 接近或后退，**A/D** 绕敌移动。再次切换恢复双人视角。选将与暂停界面不会误触开关，回到选将时关闭锁定；同场回合间保留用户选择。步战可同时按住移动方向与 **Space** 向该方向闪避，静止时向后撤。锁敌只辅助视角与朝向，实际攻击仍要接触对手。

马战锁定只标记目标并跟随镜头，不控制马身。**W/S** 调整油门与倒退，**A/D** 转马，**X** 急刹；**Z/C** 指定左右侧出手，**J/K** 自动选近侧。松键巡航，**Space** 催马沿马身前进。镜头开关不改变实际转向、攻势朝向或命中范围。
