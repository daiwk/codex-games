# 二战：装甲战线

在一张约 100 × 286 米的连续地图上带队穿越农田、翻过三道山脊，再到海边布防。沿途有六支敌军部队，进入滩头防线后迎击三批登陆部队。守住滩头才完成任务。

- 开局固定编制为 **10 辆坦克、20 名步兵和 5 架飞机**，玩家的起始坦克算在编制内。阵亡单位在同一次任务中不会补充或复活。全军覆没即任务失败。
- 沿路有 **三个一次性补给点**。进入绿色标记即可恢复所有幸存友军的生命值。首次抵达滩头防线也会补给一次，并留出 8 秒布防。画面上方会显示前往目标的方向与距离。
- 平原首领会连射三发炮弹，群山首领会呼叫援军，最后一批登陆部队的首领会用红圈预告空袭。
- 战斗中按 **Q** 可接管其他存活友军，原单位交给 AI。接管菜单支持翻页，可点击单位，或按当页 **1–7** 选中。当前单位阵亡时会打开接管菜单。
- 驾驶飞机时按 **B** 投弹。双方 AI 飞机也会投弹，每架飞机独立冷却 5 秒。爆炸会伤及附近敌军和建筑。可摧毁建筑丢失耐久后会倒塌，打开原本遮挡的路线。

可分别选择自己的起始坦克和敌军常规坦克。可选默认坦克、豹式 G 型、M26 潘兴和百夫长 Mk.3。选车页显示各车型的单发攻击、防御减伤和最大生命。暂停或结算时可以回到选车。

macOS 双击 `play.command` 启动。也可以用 Godot 4 导入 `godot/project.godot`，按 **F6** 运行 `main.tscn`，或按 **F5** 运行项目。已用 Godot 4.7.2 验证。

## 网页版

OpenAI Sites 的静态发布目录是 `dist/`。桌面浏览器中点击**开始战役**锁定鼠标，按 **Tab** 在对战中释放或重新锁定鼠标。按 **Esc** 暂停，点击**继续对战**继续。按 **F** 切换全屏。

浏览器拒绝锁定时，对战会以释放鼠标的状态继续。按 **Tab** 可以再次尝试锁定。

构建使用 Godot 4.7.2 的单线程 Web Release 模板。仓库内可复用《问锋》已有的模板缓存，也可以安装对应导出模板，或把 `web_nothreads_release.zip` 的路径传给 `--template`。

```sh
python3 tools/build_web.py
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

浏览器打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。

## 操作

| 操作 | 按键 |
| --- | --- |
| 按镜头方向移动坦克和步兵 | W、S、A、D 或方向键 |
| 驾驶飞机 | 鼠标改变航向和俯仰，W、S 沿瞄准方向前进和后退，A、D 横移 |
| 转动炮塔或调整步兵瞄准方向 | 移动鼠标，准星固定在画面中央 |
| 开火 | 空格，可按住 |
| 驾驶飞机时投弹 | B，冷却 5 秒 |
| 恢复友军生命 | 行进至绿色补给区 |
| 切换操控单位 | Q 打开列表。Page Up / Page Down 翻页，点击或按当页 1–7 接管。再按 Q 或 Esc 取消 |
| 锁定、释放鼠标 | Tab，释放时镜头保持方向 |
| 暂停 | Esc，点击按钮继续 |
| 从平原重新开始整场任务 | R |

`source-assets/` 保存原始素材。`godot/assets/` 是游戏使用的副本，坦克的车体、炮塔和炮管可以分别转动。

步枪道具采用 Lucian Pavel 发布的 CC0 1.0 模型，经转换和贴图优化后用于游戏。[OpenGameArt 素材页](https://opengameart.org/node/68099)
