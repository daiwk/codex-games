# 二战：装甲战线

用第三人称操控坦克、步兵和飞机，依次通过平原、山丘和海边。每关有两波常规敌军，第 3 波中的一辆敌方坦克为首领。击退本关全部敌军后，点击**进入下一关**，满员重新部署。打完三关即赢得战役。

| 关卡 | 友军（坦克 / 步兵 / 飞机） | 每波敌军（坦克 / 步兵 / 飞机） | 首领生命 / 攻击 |
| --- | --- | --- | --- |
| 平原 | 4 / 1 / 1 | 2 / 1 / 1 | 150 / 35 |
| 山丘 | 5 / 2 / 1 | 3 / 2 / 1 | 190 / 44 |
| 海边 | 4 / 2 / 2 | 4 / 2 / 2 | 240 / 52 |

平原的农田、村落和交叉道路各有不同掩体。豹式首领在瞄准后发出预警，随后连续发射三发炮弹。

山丘的坦克可以沿盘山路或两翼坡道开上山脊，再从另一侧驶下。潘兴首领最多呼叫两次援军，每次有一辆坦克和一名步兵加入战斗。

海边我军从沙丘后的碉堡和沙袋防线出发，敌军从登陆滩推进。百夫长首领呼叫空袭时，地面会标出即将被轰炸的区域，看到红圈后可以开出标记范围。

准星指向可摧毁的建筑时，显示当前耐久和上限。建筑倒塌后，坦克可以从原位置通过。重开本关会恢复建筑和双方编制。

开始战役前可分别选择自己的坦克和敌军常规车型。可选默认坦克、豹式 G 型、M26 潘兴和百夫长 Mk.3，双方可以选同一款。暂停或战役结算时点击**换坦克**可返回选车。

选车页显示每发基础攻击、减伤比例和生命值上限。命中时按目标的防御比例减伤，再四舍五入到整数。存活的友军进入下一波，己方步兵和飞机补足至本关编制。

战斗中按 **Q** 可以主动切换操控的单位。点击存活的友军，或按列表对应的 **1–7** 选择。再按 **Q** 或 **Esc** 可返回当前单位。当前单位失去战斗能力时，游戏会暂停并自动打开接管列表。

驾驶飞机时按 **B** 从机腹投弹，友军和敌军的 AI 飞机也会投弹。每架飞机有独立的 5 秒冷却，玩家的状态显示在右下角。爆炸只伤害落点附近的对方单位和建筑。投弹在每波战斗期间可用。

每关前两波结束后各有 9 秒休整。当前操控的单位存活且受损时，可按 **H** 恢复至满生命，每次休整可用一次。幸存队友会自动恢复最多 65% 的最大生命。

发射的弹体使用金属炮弹模型，后方带短曳光，方便看清飞行方向。

macOS 双击 `play.command` 启动。也可以用 Godot 4 导入 `godot/project.godot`，按 **F6** 运行打开的 `main.tscn`，或按 **F5** 运行项目。已用 Godot 4.7.2 验证。

## 网页版

OpenAI Sites 的静态发布目录是 `dist/`。桌面浏览器中点击**开始战役**锁定鼠标，按 **Tab** 在对战中释放或重新锁定鼠标。按 **Esc** 暂停，点击**继续对战**继续。按 **F** 切换全屏。

浏览器拒绝锁定时，对战会以释放鼠标的状态继续。按 **Tab** 可以再次尝试锁定。

构建使用 Godot 4.7.2 的单线程 Web Release 模板。仓库内可复用《问锋》已有的模板缓存，也可以安装对应导出模板，或把 `web_nothreads_release.zip` 的路径传给 `--template`。

```sh
python3 tools/build_web.py
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

浏览器打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。

## 操作

| 操作 | 按键 |
| --- | --- |
| 按镜头方向移动坦克和步兵 | W、S、A、D 或方向键 |
| 驾驶飞机 | 鼠标改变航向和俯仰，W、S 沿瞄准方向前进和后退，A、D 横移 |
| 转动炮塔或调整步兵瞄准方向 | 移动鼠标，准星固定在画面中央 |
| 开火 | 空格，可按住 |
| 驾驶飞机时投弹 | B，冷却 5 秒 |
| 休整时恢复当前单位 | H，每次休整可用一次 |
| 切换操控单位 | Q 打开列表，点击或按对应的 1–7 选择。再按 Q 或 Esc 取消 |
| 锁定、释放鼠标 | Tab，释放时镜头保持方向 |
| 暂停 | Esc，点击按钮继续 |
| 从本关第 1 波重开 | R |

`source-assets/` 保存原始素材。`godot/assets/` 是游戏使用的副本，坦克的车体、炮塔和炮管可以分别转动。

步枪道具采用 Lucian Pavel 发布的 CC0 1.0 模型，经转换和贴图优化后用于游戏。[OpenGameArt 素材页](https://opengameart.org/node/68099)
