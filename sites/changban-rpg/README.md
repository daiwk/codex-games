# 长坂行 · 赵云传

独立的骑马探索RPG网站，以赵云为主角，在三国郊野中清剿游骑、升级、收集装备并依次挑战五位武将。故事为架空外传。

本目录保存专属网页入口、封面、构建工具和导出的静态网站。Godot游戏代码与模型原件复用同仓库的 `../wenfeng-web/`：RPG入口为 `../wenfeng-web/godot/rpg.tscn`，准备素材仍在 `../wenfeng-web/source-assets/`。不再复制一套人物、兵器、马匹GLB。

RPG独有的山贼原件另存于本目录 `source-assets/characters/山贼.glb`，哈希见 `source-assets/glb-manifest.json`。`tools/prepare_bandit.py` 复用共享动作参考，重建损坏的原始绑定并生成共享运行项目中的 `assets/characters/bandit.glb`；原始几何、UV及材质不替换为其他武将。这份用户素材不声明为CC0，动作许可随站点一起发布。

构建需要本地已有Godot 4.7.2及 `../wenfeng-web/.cache/web_nothreads_release.zip`，工具不会下载依赖：

```sh
python3 sites/changban-rpg/tools/build_web.py --godot /path/to/Godot
```

构建时临时切换共享工程的主场景、名称和HTML导出入口，并在 `finally` 中按原字节恢复 `project.godot` 与 `export_presets.cfg`。共享工程的两种网站导出应顺序运行。只更新本目录的 `dist/`，不更新问锋的网站输出。

导出的 `dist/` 自包含，可独立部署到静态托管。引擎与资源包按gzip压缩，较大的压缩包切成16MiB分片，每个发布文件小于25MiB。游戏代码在PCK内，浏览器运行不请求仓库里的共享目录。许可与制作信息随包放在 `dist/licenses/` 和 `dist/credits.txt`。

本地预览已构建的网站：

```sh
python3 play.py --game rpg
python3 play.py --game rpg --check
```

在仓库根目录运行以上命令，也可双击 `play-rpg.command`（macOS）或 `play-rpg.bat`（Windows）。默认访问 `http://127.0.0.1:8000`，端口被占用时启动脚本会打印另一个空闲端口。

WASD策马；按 **Tab** 或单击**鼠标中键**锁定、解除附近的敌人，按 **R** 切换目标。锁定时 **W/S** 朝敌进退，**A/D** 绕敌移动，人物与镜头保持面向目标。按住中键拖动会解除锁定并转动自由视角，滚轮调整镜头远近。解除锁定后恢复自由骑行。

Space冲刺，J/K攻击，L/Shift格挡，Q/E/U技能，F交互，I行囊，M地图，N静音，Enter继续对话，Esc暂停；倒下时按R回营。全屏使用网页顶栏按钮。进度自动保存在当前浏览器；不同网站域名的存档各自独立。

RPG玩家普攻以原动作的72%时长完整播放，接触窗口同步调整；短按事件保留240毫秒墙钟缓冲，暂停、面板、失焦与场景切换清空。锁敌且目标在3.4米内时，普攻通过有碰撞的有限进退步调整刺击或斩击距离；远处仍需主动接近。连招每段重新瞄准，已经进入有效窗口的兵器保持方向；轻击有效窗口结束70毫秒后，可接重击、技能或冲刺，资源与冷却仍正常消耗。杂兵普通轻击仍造成正常伤害，但不会打断玩家已经开始的普攻出手；重击、守将攻击、技能命中与有效窗口结束后的受击仍正常打断。

五处守将依次为：马超（2级）、许褚（4级）、张飞（6级）、关羽（8级）、吕布（10级）。挑战须同时达到等级并完成前一场试炼。首胜奖励为护腕、战甲、蛇矛、青龙刀、画戟及经验；装备在行囊中装配，兵器切换也会切换突刺或挥砍动作。流寇约45秒后重生，可持续历练。驿站恢复生命与体力，失利后回营保留等级和战利品。故事为架空外传。

后续场景与物件建模说明见 [ASSET_PROMPTS.md](ASSET_PROMPTS.md)。

RPG技能表现由专属入口 `rpg_skill_fx.gd` 复用共享 `skill_fx.gd` 与 `textured_skill_fx.gd`：枪矛保留螺旋枪芒与锋线，长刀和画戟使用弧形刀气，颜色按武将呈现。蓄势、释放、每次真实出招及收招分别触发表现，定向终结技不再用周身圆圈代替刀枪方向；震喝等径向技能保留相应周身效果。真实接触才触发命中火星、短暂顿帧及镜头微震，特效不改变伤害范围。

2026-10-24起，烟尘、火星、柔光聚能与刀枪光痕使用 [Kenney Particle Pack 1.1](https://kenney.nl/assets/particle-pack) 中五张CC0透明纹理，并与缓存程序网格合批呈现。五张运行图均为256×256，合计113,569字节；原图、许可、来源和SHA256保存在共享目录 `../wenfeng-web/source-assets/vfx/kenney/`，许可随两款站点发布。统一最多24组短时效果、每批最多32粒子；暂停冻结，打断或切场景可清理，不依赖bloom。镜头继续避开旗面、营门屋顶和建筑，收近后仍可策马穿行。

网页版3D渲染使用72%内部比例，HUD与文字保留显示分辨率，减少Retina全像素3D的负担；原角色模型与贴图不变。

本轮同步了《问锋》的动作优化：步战方向切换保留步态相位和连续播放速率，六武将烘焙步态保留16%的作者上身摆动；共用 `combat_motion.gd` 添加小幅腰胸惯性与呼吸。骑手腰胸响应真实马鞍倾斜、转弯、加减速，同时保留髋部座点、双腿净空及双手握杆。马匹和骑手每次骨骼更新后均重新对齐座点与兵器，避免低帧率的多物理帧追赶造成脱离马鞍。攻击有效窗口和大招不叠加程序姿态，普通枪矛攻击继续纯刺与物理接触；角色技能按共享独立招式更新，锁定、装备、升级与存档规则保留。

这些改动维护在共享Godot源码中，RPG通过 `RPGActor` 继承，网站仍保留独立入口、构建、Site身份及存档。本轮检查进展汇总于 `../wenfeng-web/qa/progress.md`；最终原生/浏览器复测、导出及Sites部署结果由发布流程补记。


第二轮表现对照进一步同步到RPG：普通轻重击只调整上半身的蓄势、加速与收招节奏，髋腿保持原脚步；破风声等待真正出手。刀气变为有暗边、彩色刃面与蚀散尾部的扫描曲面，枪刺有窄芯和前向压力雾，真实接触才生成局部火花、灰尘与碎屑。两款共用有上限的墙钟停顿和弹簧镜头回弹；RPG锁定镜头平滑转向，并继续对最终位置做遮挡检查。参考来源和实际查看范围见共享 [表现参考记录](../wenfeng-web/source-assets/vfx/kenney/PRESENTATION_REFERENCES.md)。新增素材全部免费，未把参考作品的资源加入游戏。

## 跳跃与空中出招（2026-10-27）

按 **V** 跳跃，触屏可点 **跳跃 V**；《问锋》步战/马战和《长坂行》骑战均可使用。Space保留闪避/催马或冲刺，F保留原来的全屏（单挑）/交互（RPG），没有新增手柄绑定。跳跃是独立的竖直状态，空中仍可轻重击、格挡和施放Q/E/U，原技能资源、冷却、数量与接触规则保留。

刀矛、抛掷和阵列从施放时的实际高度生成，按原路线经过真实受击体积才命中。刀气/战吼等压力前沿也在释放高度扩散；不会强制把角色或特效拉到世界地面，也不会对完全低于该高度的目标补虚拟伤害。空中施展不保证每次命中：兵器从目标上方经过或对方离开路线时应当落空，墙体阻挡仍有效。

起跳与真实落地只使用已有CC0烟尘、程序碎屑和既有合成声音，仍在24层短时表现预算内。触屏跳跃按钮填入技能区原来的空位，失焦、暂停、取消触摸时按原输入清理流程释放。字体补充保留旧字符集合；原始模型与付费素材策略不变。
